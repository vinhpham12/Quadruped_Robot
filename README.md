# Quadruped_Robot
A custom-designed 12-DOF quadruped robot platform featuring a modular 3D-printed chassis and a dedicated embedded controller board.

## Project Structure

* **hardware/**: 
  * `cad/`: Mechanical assembly, STEP files, and 3D printable STL files (SolidWorks).
  * `pcb/`: Custom mainboard schematics, PCB layout, and gerber files (KiCad).
